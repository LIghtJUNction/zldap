# Changelog

## 0.1.0

- Add bounded borrowed BER framing, signed scalars, nonrecursive validation and a reverse writer.
- Add LDAP Bind, Search, SearchResultEntry, SearchResultDone and Unbind codecs.
- Support all ten RFC 4511 Filter choices, simple/SASL protocol fields, controls and referrals.
- Enforce message, nesting, field, primitive-value and caller-workspace limits.
- Add transactional typed encoding and structured errors with input offsets.
- Add stable/MSRV 1.74, platform, embedded/WASM, Miri and package validation.
- Add fixed-version differential benchmarks and one-run version bump/publication workflows.
